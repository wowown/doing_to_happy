# 训练记录 · 自己用的健身重量本

一个单页应用，记每次训练的动作、组数、重量、次数，自动算容量、PR 和进步曲线。
数据只存在你打开它的那个浏览器里，不上传任何地方。

## 怎么用

1. 双击 `index.html`，用 Chrome 或 Edge 打开（不需要装任何东西，不需要联网）。
2. 上面选动作 → 点「+ 加动作」→ 填重量和次数 → 点「保存这次训练」。
3. 想看曲线长什么样，在地址栏加 `?demo=1` 打开预览（示例数据不会保存）。

手机上用的办法：先把这些文件放进手机能访问的位置，再用浏览器打开。更省事的做法是把这个目录用一条本地服务器托管，然后在手机浏览器里「添加到主屏幕」，用起来跟 App 一样。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构和样式，双击就能打开 |
| `logic.js` | 纯计算：容量、PR、历史查询、数据清洗。不碰界面，所以能用 node 直接测 |
| `app.js` | 界面逻辑：把数据画成页面、把点击变成数据、读写 localStorage |
| `test/logic.test.js` | 23 条单元测试，验证「算得对」 |
| `test/browser-check.mjs` | 在真浏览器里自动点一遍并截图，验证「点得动」 |
| `shot/` | 上面那个脚本生成的截图 |

## 怎么验证它是对的

```bash
# 1. 逻辑测试：不需要装任何依赖
node test/logic.test.js

# 2. 真浏览器验证：会自己起服务器、点一遍、截图到 shot/
node test/browser-check.mjs
```

两个都得绿了才算改完。这是「改一行就跑一遍」的成本下限——低于这个成本，人就不会去验证。

## 数据存在哪

浏览器 localStorage 的 `fitness-tracker-v1` 键。容量上限约 5MB，按现在的记录量够用很多年。

**会丢数据的三种情况**：换电脑、清浏览器缓存、用无痕模式。所以有个「导出 JSON」按钮，想换设备前点一下。导入是合并、不覆盖，可以放心多导几次。

## 想改东西的时候

改哪个文件，看你要改的是「算」还是「看」：

- 计算规则（多算一个指标、PR 换别的口径、加体重记录）→ 改 `logic.js`，然后补一条测试到 `test/logic.test.js`。
- 界面（配色、布局、多一个按钮）→ 改 `index.html` 里的 `<style>` 和 `app.js`。
- 默认动作库 → `logic.js` 顶部 `DEFAULT_EXERCISES` 数组，加几个字符串就行。

改完记得跑上面那两条命令。

## 已知的坑

- 日期用的是本机时区，跨时区旅行时「今天」可能跟你以为的不一样。
- 同一个动作在同一天记两次，会合并成一次训练（不是 bug，是故意合并的）。
- 曲线显示的是「当天最好一组的重量」，不是容量；容量在历史列表里。
